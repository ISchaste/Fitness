# Техническое задание Часть II

REST API для управления фитнес-центром.

---

## Технологии

- Python 3.11
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn

---

## Структура проекта

- `app/main.py` — запуск приложения
- `app/models.py` — модели базы данных
- `app/clients.py` — API клиентов
- `app/trainers.py` — API тренеров
- `app/lockers.py` — API шкафчиков
- `app/services.py` — API услуг
- `app/database.py` — подключение БД
- `app/seed.py` — начальные данные

---

## Функционал

### Клиенты
- создание клиента
- получение списка клиентов
- получение клиента по ID
- изменение статуса клиента
- назначение тренера
- назначение шкафчика
- добавление услуг
- получение деталей

### Тренеры
- создание тренера
- получение списка тренеров
- обновление данных
- изменение статуса

### Шкафчики
- список всех шкафчиков со статусом "занят ли?"

### Услуги
- список услуг
- получение информации об услуге
