# Техническое задание Часть I

## Выбор технологий

Проект реализован на Python с использованием:
- FastAPI
- Uvicorn
- Pydantic

Данные хранятся в оперативной памяти.
После перезапуска сервера данные сбрасываются.

---

## Шаги по реализации

1. Создан FastAPI проект и настроены роутеры `/api/clients` и `/api/trainers`
2. Реализованы модели Client и Trainer с использованием Pydantic
3. Настроено in-memory хранилище (dict)
4. Реализованы CRUD операции для Клиентов и Тренеров
5. Добавлена связь "Клиент → Тренер"
6. Реализованы Детали в endpoints с вложенными данными
7. Добавлена валидация входных данных и обработка ошибок (404, 400)
